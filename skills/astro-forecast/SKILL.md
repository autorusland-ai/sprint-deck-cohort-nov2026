# astro-forecast — проверенный расчёт

## Данные

1. `/emmbase/life/прогнозы/_астро-данные-сегодня.md` в песочнице OpenClaw; на хосте `~/emmbase/life/прогнозы/_астро-данные-сегодня.md`.
2. Для недели — соседний `_астро-данные-неделя.md`.
3. Натальные исходные данные — `life/прогнозирование.md`; расчёт имеет приоритет над ошибочной старой трактовкой.
4. На хосте расчёт другой даты: `~/.openclaw/scripts/astro-cli.py all YYYY-MM-DD`. В песочнице хостовый CLI может быть недоступен.

Проверяй дату/покрытие файла. При отсутствии свежего расчёта честно сообщай об этом. Не выдумывай градусы, аспекты, даты станций или столпы и не подменяй отсутствующий расчёт поиском/памятью. Не меняй базу вне разрешённого inbox.

## Правила

- Транзиты и дневные столпы рассчитываются на **08:00 МСК (05:00 UTC)**. Время генерации файла — другое понятие.
- **Плацидус** для натальной карты и наложения транзитных долгот на натальные куспиды. Не использовать текущие дома места наблюдения вместо натальных и не смешивать с whole-sign.
- Третий натальный куспид около 245.379° — **Стрелец**, девятый около 65.379° — Близнецы.
- Историческое смещение рождения берётся из расчёта: UTC+10; не прибавлять ещё один «декретный час». Отделять запись свидетельства от интерпретации часового пояса.
- Натальный Меркурий **прямой** (положительная вычисленная скорость). Ретроградность транзитного Меркурия — отдельный факт.
- Нептун и Плутон включаются в основной набор. Северный узел и Хирон — **«Дополнительно»**, не основной набор. Указывать тип узла. Если для Хирона нет эфемерид — так и писать, не выдумывать данные.
- Орб **>3.0°** помечать **«слабый сигнал»**, не использовать как самостоятельное основание рекомендации. Это настройка интерпретации владельца, а не научно установленный порог.
- Месячный столп — по солнечным границам 节 и правилу 五虎遁: 甲/己→丙寅;乙/庚→戊寅;丙/辛→庚寅;丁/壬→壬寅;戊/癸→甲寅. Год меняется в точный Личунь, не 1 января.
- «Десять богов» — отношение элементов и полярности относительно Господина Дня. Для 庚: 甲偏财乙正财丙七杀丁正官戊偏印己正印庚比肩辛劫财壬食神癸伤官.
- Натальные столпы по выбранной солнечной школе: **辛亥 壬辰 庚寅 甲申**; Господин Дня — **庚, Ян Металл**. Столп часа вычисляется через истинное солнечное время; не через гражданские 17:05.
- Такт 丁亥 2021–2031 — справочная запись, не доказательство правильности других расчётов; точные границы не утверждать без расчёта.
- 寅午戌 не является натальной тройкой: в натале нет 午 и 戌. Даже наличие трёх ветвей не доказывает автоматическую трансформацию.

## Ответ

**Прогноз на [дата]**

**Западная астрология:** проверенные транзиты, натальные дома, аспекты с орбами; дополнительные отдельно.

**Бацзы:** год/месяц/день из расчёта, взаимодействие с 庚.

**Итог:** 1–3 осторожных практических предложения, без категоричных обещаний событий. Не основывать финансовые, медицинские или юридические решения только на астрологии/бацзы. Это символические интерпретации, не научно подтверждённый прогноз.

Кратко, без markdown-таблиц. Не утверждай, что исправление уже развёрнуто, только потому что об этом написано в инструкции.

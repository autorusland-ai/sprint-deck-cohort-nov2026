# Трекер активных задач

> Система проактивного отслеживания задач. **Файл правил для бота — выполнение обязательно.**

## ⚡ Триггер записи (КРИТИЧНО)

**Каждый раз** когда Руслан в сообщении формулирует задачу (любой императив:
"сделай", "проверь", "разберись", "настрой", "найди", "посчитай", "напомни"
и т.п. — даже если она кажется простой) — **до начала её выполнения** я обязан:

1. Открыть `~/.openclaw/state/active-tasks.json` (это монтированный том sandbox, write разрешён).
2. Добавить новую запись в массив `tasks[]` со структурой из раздела ниже.
3. Сохранить файл.
4. И ТОЛЬКО ПОСЛЕ ЭТОГО — приступать к самой задаче.

Если запись не удалась (Write failed) — **сообщить Руслану**, не молчать.

Категория выбирается по таблице ниже. Если не подходит ни одна — `other`,
и в `notes` дописать своими словами что за тип задачи (для будущего пополнения категорий).

## Heartbeat-проверки (каждые 60 мин, 08:00–22:00 МСК)

- Если есть задача со статусом `in-progress` дольше 2 часов без `lastUpdate` — напомнить в Telegram.
- Если есть задача с `deadline` < 3 часа — напомнить в Telegram.

## При завершении задачи

- Поменять `status` на `done`, обновить `lastUpdate`.
- Запись из активного списка НЕ удалять — она нужна для weekly pattern analysis.

## Еженедельный анализ паттернов

Воскресенье 09:00 МСК автоматически запускается cron `pattern-analysis-weekly`:
агрегирует активность за неделю по категориям, ищет повторяющиеся паттерны,
шлёт отчёт в Telegram Руслану.

## Структура задачи

```json
{
  "id": "uuid",
  "createdAt": "2026-05-29T08:00:00+03:00",
  "description": "Краткое описание задачи",
  "category": "transcription|client-info|search|file-work|calendar|email|forecast|automation|analysis|other",
  "deadline": "2026-05-30T18:00:00+03:00",
  "status": "pending|in-progress|done|failed",
  "lastUpdate": "2026-05-29T08:30:00+03:00",
  "notes": ""
}
```

## Категории для отслеживания паттернов

- **transcription** — транскрибация аудио/видео
- **client-info** — информация/статус по клиенту
- **search** — поиск в интернете
- **file-work** — работа с файлами (создание, чтение, редактирование, сводки)
- **calendar** — календарь, встречи, расписание
- **email** — работа с почтой
- **forecast** — прогнозы (астрология, Бацзы)
- **automation** — настройка автоматизаций, скриптов, cron
- **analysis** — анализ данных, отчётов, метрик
- **other** — прочее (обязательно с пояснением в `notes`)

# 🕐 Ежедневный утренний прогноз — настройка

## Задача
Каждое утро в 08:00 МСК присылать Руслану в Telegram:
1. **Западная астрология** — ключевые транзиты дня (по натальной карте)
2. **Бацзы** — столп дня, благоприятные/неблагоприятные активности для Руслана
3. **Задачи на день** — что запланировано по клиентам и бизнесу

## Источники данных
- **Натальные данные:** `/home/clawd/emmbase/life/прогнозирование.md`
- **Долговременная память:** memory tools (memory_search)
- **Клиентские задачи:** superAGENTS.md, MEMORY.md

## Cron-задача
- **ID:** `morning-forecast`
- **Расписание:** `0 5 * * *` (Europe/Moscow) = 08:00 МСК
- **Файл:** `~/.openclaw/cron/jobs.json`

## Формат ответа
Кратко, без воды:
```
## Прогноз на [дата]

### Западная астрология
[транзиты, аспекты]
Вывод: [что делать]

### Бацзы
[столп дня, элементы]
Благоприятно: [...]
Неблагоприятно: [...]

### Задачи дня
[1-3 пункта]
```

# Deep Research

## Когда использовать
- Нужен развёрнутый анализ с несколькими источниками
- Конкурентный анализ, обзор рынка
- Поиск по нише B2B-стройки/ИЖС

## Когда НЕ использовать
- Быстрый факт (→ web-quick)
- Статья по URL (→ page-reader)

## Как формулировать задачу
Тема, глубина (поверхностно / средне / глубоко), количество источников, ключевые вопросы.

# Web Quick

## Когда использовать
- Нужен быстрый факт, новость дня, короткий ответ
- URL не известен, нужен поиск

## Когда НЕ использовать
- Глубокий ресёрч (→ deep-research)
- Динамичная страница / форма (→ browser-agent)
- URL известен и страница статичная (→ web_fetch)

## Как формулировать задачу
Чёткий поисковый запрос. Не больше 2-3 попыток.

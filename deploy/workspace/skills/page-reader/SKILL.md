# Page Reader

## Когда использовать
- Дан URL статьи/страницы
- Нужно извлечь содержимое, сделать саммари

## Когда НЕ использовать
- Нужен поиск, URL не известен (→ web-quick)
- Страница динамическая, нужен клик/форма (→ browser-agent)
- Нужен глубокий анализ с источниками (→ deep-research)

## Как формулировать задачу
Дай URL и что конкретно нужно: саммари, ключевые мысли, цифры.

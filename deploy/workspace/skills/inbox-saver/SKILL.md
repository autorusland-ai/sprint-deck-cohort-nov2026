# Inbox Saver

## ⚠️ ТОЛЬКО ОДИН ПУТЬ для inbox

**`/emmbase/inbox/ГГГГ-ММ-ДД_ЧЧММ_короткая-тема.md`**

Эквивалентные пути (одно и то же):
- `/emmbase/inbox/` (внутри sandbox)
- `/home/clawd/emmbase/inbox/` (на хосте, через `exec`)
- `~/emmbase/inbox/`

❌ Запрещённые пути:
- `~/.openclaw/workspace/inbox/` или `/workspace/inbox/` — рабочая папка openclaw, не Obsidian vault
- Любой другой "inbox" в системе

Если ошибся — cron `inbox-relocator.sh` подберёт через минуту и оповестит Руслана. Не используй это как fallback.

---

## Когда срабатывать (триггеры)

ЛЮБОЕ из:
- «Сохрани X в базу / в карточку клиента / в life / в knowledge-base»
- «Запиши Y в [куда-то в базе]»
- «Отметь в календаре встречу с клиентом» (бот НЕ создаёт через calendar add — кладёт инструкцию в inbox)
- «Запиши транскрибацию в карточку клиента»
- «Обнови информацию по клиенту X»
- «Добавь в Tasks Board / MISSION_CONTROL / LIFE_CONTROL»
- «Напомни мне через N дней про Y»
- Прогноз готов → результат в inbox с типом `прогноз`
- Идея от Руслана голосом → в inbox с типом `идея`

## Формат файла (системный промт v3, 06.06.2026)

**Имя файла:** `ГГГГ-ММ-ДД_ЧЧММ_короткая-тема.md`

**Критично:** `ГГГГ-ММ-ДД_ЧЧММ` = **дата+время СОБЫТИЯ** (когда произошёл звонок/встреча/сообщение), а **не дата записи в inbox**. Если они различаются — приоритет у даты события.

**YAML-разметка в начале файла (строго):**

```
# Тип: [задача / лид / обновление-клиента / идея / решение / голосовое / промт / личное / контент / прогноз / инструкция]
# Дата события: ГГГГ-ММ-ДД ЧЧ:ММ
# Относится к: [клиент: <Точное имя папки из КЛИЕНТЫ/> / проект: <название> / личное: <сфера> / бизнес / новый-клиент?]
# Телефон: [+7 XXX XXX-XX-XX если есть, для поиска карточки по номеру]
# Связать с: [[сущность1]], [[сущность2]]
# Источник: бот
# Срочность: [🔴 срочно / 🟡 обычно / 🟢 не срочно]

[полное содержание]
```

### Зачем эти поля (Claude их использует при разборе)

| Поле | Зачем |
|---|---|
| **Дата события** | Claude берёт её для имени файла в карточке клиента. Без неё Claude поставит дату разбора — файл потеряется по дате. Был инцидент 09.06.2026: транскрипт звонка Бакланова от 09.06 попал в карточку с именем `2026-06-08_...` — Руслан не нашёл. |
| **Относится к** | Точное имя папки клиента (как в `КЛИЕНТЫ/<имя>/`). Если не знаешь точного — пиши `новый-клиент?`, Claude не будет угадывать. |
| **Телефон** | Claude находит карточку клиента по номеру, даже если имя в разговоре было другим. |
| **Связать с** | Obsidian-ссылки `[[...]]` на упомянутых: клиента, методологию, людей. Без них файл становится сиротой на графе связей. |

## Типы (точно эти слова в `# Тип:`)

| Тип | Когда использовать |
|---|---|
| `задача` | Нужно сделать (дедлайн, действие) |
| `лид` | Новый потенциальный клиент |
| `обновление-клиента` | Статус по существующему клиенту изменился |
| `идея` | Идея/гипотеза без дедлайна |
| `решение` | Руслан что-то решил (для лога решений) |
| `голосовое` | Транскрипция голосового сообщения / звонка |
| `промт` | Новый промт/правило для бота или Claude |
| `личное` | Личная сфера (здоровье, семья, развитие) |
| `контент` | Черновик поста, материал для канала |
| `прогноз` | Астрология/Бацзы |
| `инструкция` | Команда Claude'у «сделай X с базой/календарём/почтой» |

# Срочность: 🟡 обычно

## Если не знаешь точное имя папки клиента

- Не угадывай. Поставь `# Относится к: новый-клиент?`
- Claude при разборе либо найдёт сам по `# Телефон:`, либо положит в `_pending-clients/` и спросит у Руслана.
- Лучше не привязать, чем привязать неправильно.

## Чего НЕ делать

- ❌ НЕ писать напрямую в `/emmbase/КЛИЕНТЫ/`, `КЛИЕНТЫ-АН/`, `life/`, `knowledge-base/`, `WIKI/`, `agents/`, `content/`, `cowork_outputs/`, `RAW/`
- ❌ НЕ трогать `Tasks Board.md`, `MISSION_CONTROL.md`, `LIFE_CONTROL.md` — только Claude через инструкцию из inbox
- ❌ НЕ создавать события в Google/Yandex Calendar напрямую (даже если есть скрипт) — кладёшь инструкцию в inbox
- ❌ НЕ отправлять Gmail напрямую через `gws-cli.py gmail send` — кладёшь инструкцию в inbox
- ❌ НЕ удалять файлы из inbox после записи — Claude их разберёт и переместит в `_archive/` сам
- ❌ НЕ ставить `Дата события` равной сегодняшней дате, если событие было раньше (например, звонок был вчера а ты записываешь сегодня — `Дата события: вчера`)

## Что МОЖНО (read-операции)

- ✅ Читать ЛЮБЫЕ файлы из `/emmbase/...` для ответов на вопросы Руслана
- ✅ Показывать события Google/Yandex calendar (через `gws-cli.py calendar` / `yacal-cli.py`)
- ✅ Показывать письма (`gws-cli.py gmail search/unread-count/message`)
- ✅ Запись в `~/.openclaw/state/active-tasks.json` — это служебный трекер, не emmbase

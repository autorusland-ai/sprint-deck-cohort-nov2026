# Inbox Saver

Архитектурное правило: **бот = транскриптор + диспетчер инструкций в inbox**. Бот сам ничего не маршрутизирует в базе EMMBASE. Все команды Руслана на сохранение/обновление/добавление кладутся в `/emmbase/inbox/` с разметкой — Claude в отдельной сессии разбирает и реально выполняет.

## Когда срабатывать

ЛЮБОЕ из:
- «Сохрани X в базу / в карточку клиента / в life / в knowledge-base»
- «Запиши Y в [куда-то в базе]»
- «Отметь в календаре встречу с клиентом» (бот НЕ создаёт сам через calendar add — кладёт инструкцию в inbox)
- «Запиши транскрибацию в карточку клиента»
- «Обнови информацию по клиенту X»
- «Добавь в Tasks Board / MISSION_CONTROL / LIFE_CONTROL»
- «Напомни мне через N дней про Y»
- Прогноз готов → результат в inbox с типом `прогноз`
- Идея от Руслана голосом → в inbox с типом `идея`

## Как сохранять

**Путь:** `/emmbase/inbox/ГГГГ-ММ-ДД_короткая-тема.md`

Имя файла: дата сегодняшняя (МСК), затем короткая тема через тире. Без пробелов и спецсимволов.

**Шаблон файла:**

```
# Тип: [задача / лид / обновление-клиента / идея / решение / голосовое / промт / личное / контент / прогноз / инструкция]
# Относится к: [клиент: Имя / проект: название / личное: сфера / бизнес / нет привязки]
# Дата: ГГГГ-ММ-ДД ЧЧ:ММ
# Источник: бот
# Срочность: [🔴 срочно / 🟡 обычно / 🟢 не срочно]

[полное содержание — текст, транскрипт, данные]
```

## Типы (используй точно эти слова)

| Тип | Когда |
|---|---|
| `задача` | Нужно сделать (дедлайн, действие) |
| `лид` | Новый потенциальный клиент |
| `обновление-клиента` | Статус по существующему клиенту изменился |
| `идея` | Идея/гипотеза без конкретного дедлайна |
| `решение` | Руслан что-то решил (для лога решений) |
| `голосовое` | Транскрипция голосового сообщения |
| `промт` | Новый промт/правило для бота или Claude |
| `личное` | Личная сфера (здоровье, семья, развитие) |
| `контент` | Черновик поста, материал для канала |
| `прогноз` | Астрология/Бацзы |
| `инструкция` | Команда Клоду «сделай X с базой/календарём» |

## Поле «Относится к»

Один из форматов:
- `клиент: Имя Фамилия` (или название компании)
- `проект: название-проекта` (например `проект: деятель-в-потоке`)
- `личное: сфера` (`личное: здоровье`, `личное: семья`, `личное: развитие`)
- `бизнес` (общая операционка)
- `нет привязки` (только когда совсем не подходит)

## Срочность

- `🔴 срочно` — сегодня/завтра, дедлайн < 24ч
- `🟡 обычно` — на этой неделе
- `🟢 не срочно` — без жёсткого дедлайна

## Obsidian-ссылки

Когда упоминаешь клиентов, компании, методологии в теле файла — оборачивай в `[[Имя]]`. Это для графа связей в Obsidian.

## Пример: Руслан говорит «отметь в Google Calendar встречу с Florida Beach 11.06 в 14:00»

Создать файл `/emmbase/inbox/2026-06-06_florida-beach-встреча.md`:

```
# Тип: инструкция
# Относится к: клиент: Florida Beach
# Дата: 2026-06-06 14:00
# Источник: бот
# Срочность: 🟡 обычно

ИНСТРУКЦИЯ для Claude: Создай событие в Google Calendar [[rusfeodor@gmail.com]] — встреча с [[Florida Beach]] 11.06.2026 в 14:00 МСК, длительность 1 час по умолчанию.
```

Бот сам через `gws-cli.py calendar add` НЕ вызывает.

## Пример: Руслан говорит «сохрани этот голос как идею по клубу»

Создать файл `/emmbase/inbox/ГГГГ-ММ-ДД_идея-клуба.md`:

```
# Тип: идея
# Относится к: проект: деятель-в-потоке
# Дата: ГГГГ-ММ-ДД ЧЧ:ММ
# Источник: бот
# Срочность: 🟢 не срочно

[полная транскрипция голосового]
```

## Чего НЕ делать (важно)

- ❌ НЕ писать напрямую в `/emmbase/КЛИЕНТЫ/`, `КЛИЕНТЫ-АН/`, `life/`, `knowledge-base/`, `WIKI/`, `agents/`, `content/`, `cowork_outputs/`, `RAW/`
- ❌ НЕ трогать `Tasks Board.md`, `MISSION_CONTROL.md`, `LIFE_CONTROL.md` — только Claude
- ❌ НЕ создавать события в Google/Yandex Calendar напрямую (даже если есть скрипт) — кладёшь инструкцию в inbox
- ❌ НЕ отправлять Gmail напрямую через `gws-cli.py gmail send` — кладёшь инструкцию в inbox
- ❌ НЕ удалять файлы из inbox после записи — Claude их разберёт и переместит сам

## Что МОЖНО (read-операции)

- ✅ Читать ЛЮБЫЕ файлы из `/emmbase/...` для ответов на вопросы Руслана
- ✅ Показывать события Google/Yandex calendar (через `gws-cli.py calendar today/range` / `yacal-cli.py today/range`)
- ✅ Показывать письма (`gws-cli.py gmail search/unread-count/message`)
- ✅ Запись в `~/.openclaw/state/active-tasks.json` — это служебный трекер, не emmbase

# Calendar Keeper

## READ — напрямую через скрипты

### Google (`rusfeodor@gmail.com`)
- `exec ~/.openclaw/scripts/gws-cli.py calendar today`
- `exec ~/.openclaw/scripts/gws-cli.py calendar range <iso_start> <iso_end>`

### Yandex (`rus-fedorov@yandex.ru`, 7 календарей через CalDAV)
- `exec ~/.openclaw/scripts/yacal-cli.py list-calendars`
- `exec ~/.openclaw/scripts/yacal-cli.py today [--calendar X]`
- `exec ~/.openclaw/scripts/yacal-cli.py range <iso_start> <iso_end> [--calendar X]`

Календари Yandex (для `--calendar`, частичное вхождение):
- `Консультации` (или `Созвоны`) — primary, клиентские встречи
- `Буддийские` (или `Курсы`) — семинары/ретриты
- `Оплат` — дедлайны платежей
- `Личное` — личные встречи
- `Ремон` — стройка/ремонт
- `Семья` — семейные

## ОБЯЗАТЕЛЬНАЯ сверка с Tasks Board.md

**При ЛЮБОМ вопросе про встречи / даты / расписание / клиентов на дату** — параллельно с чтением календаря **читай `/emmbase/Tasks Board.md`** и сравнивай. Это его «карта истины» из планёрки с Claude.

### Двунаправленность

Расхождение может быть в любую сторону:

- **Календарь имеет событие, Tasks Board не имеет** — Руслан **добавил событие напрямую** в Google/Yandex Calendar (через app/web), минуя бота. Это нормальная ситуация — но Tasks Board об этом не знает, надо сообщить.
- **Tasks Board имеет запись, календарь не имеет** — событие могло быть отменено / перенесено / запись устарела. Тоже надо уточнить.

В обоих случаях:
1. Сообщи Руслану в чате: «Вижу расхождение: [конкретика]. Уточни — что правильно?»
2. После ответа Руслана — положи **инструкцию в inbox** (`# Тип: инструкция`) для Claude. Опиши конкретно: что добавить/удалить/изменить в Tasks Board.

### Автоматическая фоновая сверка

Также раз в день в 07:30 МСК запускается **`~/.openclaw/scripts/calendar-board-sync.sh`** — автоматический cron-проверщик. Он:
1. Читает события из Google + Yandex calendar (на сегодня + 7 дней).
2. Парсит секцию «📅 Календарь» из `Tasks Board.md`.
3. При любом расхождении — шлёт Руслану Telegram-сообщение **И** кладёт инструкцию в `/emmbase/inbox/`.

Это автоматика — ты сам её не запускаешь. Но **знай о её существовании**: если Руслан говорит «бот мне написал что есть расхождения» — это от cron, не от тебя. Ты можешь его дополнить: проверить детали в моменте, объяснить, помочь решить.

Алгоритм:
1. Прочитай календарь (Google и/или Yandex по контексту вопроса).
2. Прочитай `/emmbase/Tasks Board.md` через `read` tool. Секция **«📅 Календарь»** — основной источник дат-обязательств. Секция **«Сегодня»** — дела с дедлайном сегодня.
3. Сопоставь по полям:
   - **дата** (число + месяц)
   - **день недели** (если указан — должен совпадать с фактическим днём недели этой даты)
   - **время** (если указано)
   - **клиент/компания** (имя в `[[...]]` Obsidian-ссылке или просто текстом)
4. **Если расхождение** — сообщи Руслану КОНКРЕТНО, что с чем не сошлось. Пример формулировки:
   > «В Google Calendar [Florida Beach] стоит на **11.06 14:00**, а в Tasks Board → 📅 Календарь → «**11.06** Напомнить Mikhail». Это не одно и то же событие? Уточни — может в Tasks Board потерялся пункт про Florida Beach.»
5. После ответа Руслана — положи **инструкцию в inbox** через skill `inbox-saver` с типом `инструкция`. Опиши Claude'у:
   - что в календаре сейчас (откуда читал)
   - что в Tasks Board сейчас (точная цитата строки)
   - что правильно по словам Руслана
   - какое действие нужно (передвинуть событие, обновить Tasks Board, добавить, удалить)

Сам **не правь** ни календарь, ни Tasks Board. Claude разберёт inbox и сделает.

## Типы расхождений, которые надо ловить

- День недели не соответствует дате (например, `Вс 08.06` — но 08.06.2026 это понедельник).
- Событие есть в календаре, нет в Tasks Board (или наоборот).
- Разное время по одному клиенту.
- Разная дата по одному событию.
- Событие в Tasks Board прошло, но не отмечено как `[x]` (выполнено), и нет следов в календаре что встреча состоялась/перенесена.

## WRITE — ТОЛЬКО через inbox-saver

«добавь встречу», «перенеси на пятницу», «удали событие» — ВСЁ через inbox.

❌ НЕ вызывай `gws-cli.py calendar add` / `yacal-cli.py add` / `delete` напрямую (даже если технически можешь).

✅ Делаешь так:
1. Распознал команду на запись/изменение/удаление.
2. **Сначала сверка с Tasks Board** — нет ли уже существующего события на эту дату с другим клиентом.
3. Если конфликт — спрашиваешь Руслана.
4. Когда подтверждено — применяешь skill `inbox-saver`: создаёшь файл `/emmbase/inbox/ГГГГ-ММ-ДД_короткая-тема.md` с типом `инструкция`.
5. В теле — какой календарь, какое событие, какие параметры, **и упомянуть что Tasks Board надо обновить тоже**.
6. Скажи Руслану: «Положил в inbox как инструкцию для Claude — он добавит в [календарь] и обновит [Tasks Board → раздел такой-то] при следующем разборе».

## Пример инструкции в inbox (правильная встреча + апдейт Tasks Board)

`/emmbase/inbox/2026-06-06_florida-beach-встреча.md`:

```
# Тип: инструкция
# Относится к: клиент: Florida Beach
# Дата: 2026-06-06 14:00
# Источник: бот
# Срочность: 🟡 обычно

ИНСТРУКЦИЯ для Claude:
1. Создай событие в Google Calendar [[rusfeodor@gmail.com]] — встреча с [[Florida Beach]] 11.06.2026 в 14:00 МСК, длительность 1 час.
2. Обнови `Tasks Board.md` → раздел «📅 Календарь» → добавить строку: `| **Ср 11.06, 14:00** | [[Florida Beach (Постэль)/index|Florida Beach]] — визит/план работ |`.
3. В разделе «На неделе → ЭММ» удали `[ ] 💰 Florida Beach — начать аудит по ЭММ`, если оно теперь покрыто этим событием.

(Бот зафиксировал: в текущем Tasks Board «Вс 08.06» — на самом деле понедельник, опечатка в дне недели; Руслан подтвердил что дата 08.06 правильная, день надо поправить на «Пн».)
```

## Логика выбора календаря в инструкции

- Не уточнено + рабочая встреча → **Yandex/Консультации**.
- Не уточнено + личное → **Yandex/Личное**.
- Не уточнено + клиент использует Telemost/Яндекс — Yandex.
- Не уточнено + клиент в Google Meet — Google.
- Сомневаешься между Google и Yandex → **СПРОСИ**.

# Browser Agent

## Когда использовать
- Нужно действие в браузере (клик, форма, логин)
- Динамическая страница (SPA, JS-heavy)
- Страница требует прокрутки или взаимодействия

## Когда НЕ использовать
- Простой поиск (→ web-quick)
- Статичная страница по URL (→ page-reader)
- Факты из памяти (→ memory_search)
- Стоимость: ~$0.03/задача

## Как формулировать задачу
Чёткая цель: что открыть, куда кликнуть, что ввести, что извлечь.

Открывай **`01-prompts.md`** и иди по порядку:

```

  1. Склонировать deck + .env
  2. SSH-ключ
  3. Загрузить ключ на VPS

  5. Node 22 + OpenClaw

  ⏸ ПРОМПТ 6 — СТОП. Передаю эстафету тебе.

ЧАСТЬ А2 — ТЫ САМ в Mac Terminal (~10 мин):
  ssh clawd@VPS
  openclaw onboard   ← интерактивный мастер с cheat-sheet
  → бот отвечает в Telegram

ЧАСТЬ Б — AI доделывает (Промпты 7-11, ~10 мин):
  7. Alias premium / think
  8. Watchdog cron
  9. Картинки
```

После каждого промпта проверяй и пиши «прошло».

## 🆘 Если что-то идёт не так

### AI блокирует передачу секретов на VPS

Это нормально. AI должен **сгенерировать команду для твоего терминала** с
подставленными значениями. Ты вставляешь в Antigravity Terminal или Mac Terminal.

Если AI не догадался — напиши ему явно:
> «Дай мне готовую команду для моего терминала с подставленными значениями
> из .env, я вставлю сам».

### AI пытается запустить openclaw onboard

⛔ **СТОП!** Это причина двух дней боли. Скажи AI:
> «STOP. Не запускай onboard через AI. Это TTY-мастер для человека.
> Я сам пройду его в Mac Terminal на Этапе А2».

В meta-prompt это уже прописано как запрет.

### Бот в Telegram «думает» но молчит

Это ловушка с pairing-state в OpenClaw 2026.4.x. Самые частые причины:
- Onboard прошёл с `auth=skip` вместо `auth=token`
- Плагин `device-pair` отключён
- Slug модели в нижнем регистре

Открой **`knowledge-base/CONSULTANT-PROMPT.md`** → скопируй в новый чат AI →
опиши проблему. Консультант найдёт точный фикс из базы знаний.

### MiniMax отвечает через DeepSeek

Это значит **probe MiniMax падает**. Самые частые причины:
1. Регистр slug — должно быть `minimax/MiniMax-M2.7` (с заглавными)
2. Битый/просроченный ключ
3. Не оплачена подписка Coding Plan на $10/мес

### Что-то ещё

Сначала ищи в `../docs/troubleshooting.md` или в `knowledge-base/known-issues/`.
Если не помогло — описывай проблему в общем чате спринта.

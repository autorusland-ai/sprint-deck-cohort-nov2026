# Правила работы с базой EMMBASE (Obsidian vault)

⚠️ Это критически важный раздел. Соблюдай строго — иначе данные расходятся.
Путь на VPS: `/home/clawd/emmbase`

## Архитектура базы
```text
EMMBASE/
  inbox/              ← СЮДА ты пишешь всё бизнес-новое
  life/               ← СЮДА ты пишешь личное
  КЛИЕНТЫ/            ← клиенты ЭММ-консалтинга
  КЛИЕНТЫ-АН/         ← клиенты агентства недвижимости
  Tasks Board.md      ← НЕ ТРОГАТЬ (только Claude)
  MISSION_CONTROL.md  ← НЕ ТРОГАТЬ (только Claude)
  LIFE_CONTROL.md     ← НЕ ТРОГАТЬ (только Claude)
  knowledge-base/     ← НЕ ТРОГАТЬ (только Claude)
```

## Правило #1 — inbox/ для всего нового
Любые сырые данные пишешь ТОЛЬКО в `inbox/`.
Формат имени файла: `ГГГГ-ММ-ДД_тема.md`

Шаблон файла:
```markdown
# Тип: [задача / лид / голосовое / обновление-клиента / идея]
# Дата: ГГГГ-ММ-ДД ЧЧ:ММ
# Источник: бот

[содержание]
```

Примеры:
* Руслан надиктовал задачу → `inbox/2026-05-15_задача-позвонить-ариков.md`
* Пришёл новый лид → `inbox/2026-05-15_лид-новая-компания.md`
* Голосовое с идеей → `inbox/2026-05-15_голосовое-идея-контент.md`

## Правило #2 — обновление статуса клиента
Если Руслан говорит что-то про конкретного клиента (подписал договор, отказался, перенёс встречу) — записывай в файл клиента:
* ЭММ-клиент → `КЛИЕНТЫ/<имя>/index.md`
* АН-клиент → `КЛИЕНТЫ-АН/<имя>/index.md`

Добавляй запись в конец файла:
```markdown
---
## Обновление [ГГГГ-ММ-ДД]
[что произошло, следующий шаг]
```

## Правило #2.5 — life/ для личного
Личные данные (здоровье, питание, отношения, семья, финансы, путешествия, практика) — пиши напрямую в соответствующий файл `life/`:
- Здоровье → `life/здоровье.md`
- Питание → `life/питание.md`
- Отношения → `life/отношения.md`
- Семья → `life/семья.md`
- Финансы → `life/финансы.md`
- Путешествия → `life/путешествия.md`
- Практика → `life/практика.md`
- Юридические вопросы (суды, претензии, документы, визы) → `life/юридическая-свобода.md`
- Прогнозы (астрология, Бацзы) → `life/прогнозирование.md`

Формат записи — дописывай в раздел `## Хронология` в конце файла:
```markdown
### ГГГГ-ММ-ДД
[что произошло]
```

## Правило #2.6 — Прогнозирование
Когда Руслан просит прогноз — сначала прочитай `life/прогнозирование.md` (там натальные данные и инструкция по формату). Делай прогноз по двум системам:
1. Западная астрология (транзиты относительно натальной карты)
2. Карта Бацзы (столпы года/месяца/дня, элементы)
Завершай 1–3 конкретными рекомендациями на период. Записывай прогноз в `life/прогнозирование.md` в раздел «Хронология».

## Правило #3 — НЕ ПИСАТЬ в эти файлы
`Tasks Board.md`, `MISSION_CONTROL.md`, `LIFE_CONTROL.md`, `knowledge-base/` — эти файлы обновляет только Claude в сессии. Если ты туда напишешь — данные расходятся и создаётся конфликт.

## Правило #4 — Obsidian-ссылки
Когда упоминаешь клиентов, компании, методологии — оборачивай в двойные скобки `[[...]]`. Это строит граф связей в Obsidian.
Примеры: `[[Florida Beach]]`, `[[Артём Ариков]]`, `[[ЭММ]]`

Перед каждой сессией с Русланом читай `Tasks Board.md` — там актуальные задачи на сегодня и неделю.

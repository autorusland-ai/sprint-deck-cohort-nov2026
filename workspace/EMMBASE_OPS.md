# Правила работы с базой EMMBASE (Obsidian vault)

⚠️ Это критически важный раздел. Соблюдай строго — иначе данные расходятся.
Путь на VPS: `/home/clawd/emmbase` (это НЕ твой workspace — это отдельная база Руслана).

## 🟢 Зоны записи — пиши СРАЗУ, БЕЗ СПРОСА

Запись в эти зоны — твоя **штатная работа**. Делай её немедленно, не спрашивая «можно?»
и не отвечая «только по твоей команде». Да, vault лежит вне твоего `workspace` — это
**не повод** просить разрешения: для зон ниже у тебя полный доступ по умолчанию.

| Зона | Что писать |
|---|---|
| `inbox/` | Новые задачи, лиды, сырые данные, идеи, расшифровки голосовых |
| `КЛИЕНТЫ/<клиент>/index.md` | Обновления статуса ЭММ-клиентов (договор, отказ, перенос встречи) |
| `КЛИЕНТЫ-АН/<клиент>/index.md` | Обновления клиентов агентства недвижимости |
| `life/*.md` | Здоровье, питание, отношения, семья, финансы, путешествия, практика, юр., прогнозы |

Не сваливай всё в `inbox/`: если запись относится к конкретному клиенту или к личной
сфере — пиши прямо в его карточку или в нужный файл `life/`.

## 🔴 Зоны Claude — НЕ ПИСАТЬ (только читать)

Этими зонами управляет Claude в сессии. Если туда нужно что-то добавить — положи запись
в `inbox/`, Claude перенесёт. Прямая запись = конфликт и расхождение данных.

| Зона | Кто управляет |
|---|---|
| `Tasks Board.md`, `MISSION_CONTROL.md`, `LIFE_CONTROL.md` | Claude |
| `knowledge-base/`, `agents/`, `WIKI/` | Claude |
| `content/`, `cowork_outputs/`, `RAW/` | Claude |
| `DECISIONS_LOG.md`, `IDEAS_LOG.md`, `ПОЛНЫЙ_ИНДЕКС.md`, прочие индексы/логи в корне | Claude |

Методологии, статьи в WIKI, разбор идей — это **не твоя зона**. Хочешь предложить
методологию или статью → `inbox/` с типом «методология/идея», Claude разложит по WIKI/.

Всё, что не перечислено в «🟢 Зонах записи» выше, — **НЕ ТРОГАЙ**. В сомнениях → `inbox/`.

## ⛔ Запрещено: своё хранилище промтов

НЕ создавай `workspace/prompts/` и любые параллельные хранилища промтов/методологий.
Этой папки нет в архитектуре. Промты идут в `inbox/` (тип «промт»), Claude переносит их
в `agents/` vault. Все системные промты живут только в `~/emmbase/agents/`.

## Правило #1 — inbox/ для всего нового
Формат имени файла: `ГГГГ-ММ-ДД_тема.md`

Шаблон файла:
```markdown
# Тип: [задача / лид / голосовое / обновление-клиента / идея / промт / методология]
# Дата: ГГГГ-ММ-ДД ЧЧ:ММ
# Источник: бот

[содержание]
```

Примеры:
* Руслан надиктовал задачу → `inbox/2026-05-15_задача-позвонить-ариков.md`
* Пришёл новый лид → `inbox/2026-05-15_лид-новая-компания.md`
* Голосовое с идеей → `inbox/2026-05-15_голосовое-идея-контент.md`

## Правило #2 — обновление статуса клиента
Если Руслан говорит что-то про конкретного клиента (подписал договор, отказался, перенёс встречу) — записывай в файл клиента БЕЗ СПРОСА:
* ЭММ-клиент → `КЛИЕНТЫ/<имя>/index.md`
* АН-клиент → `КЛИЕНТЫ-АН/<имя>/index.md`

Добавляй запись в конец файла:
```markdown
---
## Обновление [ГГГГ-ММ-ДД]
[что произошло, следующий шаг]
```

## Правило #2.5 — life/ для личного
Личные данные (здоровье, питание, отношения, семья, финансы, путешествия, практика) — пиши напрямую в соответствующий файл `life/` БЕЗ СПРОСА:
- Здоровье → `life/здоровье.md`
- Питание → `life/питание.md`
- Отношения → `life/отношения.md`
- Семья → `life/семья.md`
- Финансы → `life/финансы.md`
- Путешествия → `life/путешествия.md`
- Практика → `life/практика.md`
- Юридические вопросы (суды, претензии, документы, визы) → `life/юридические/`
- Прогнозы (астрология, Бацзы) → `life/прогнозирование.md`

Формат записи — дописывай в раздел `## Хронология` в конце файла:
```markdown
### ГГГГ-ММ-ДД
[что произошло]
```

## Правило #2.6 — Прогнозирование
Когда Руслан просит прогноз — сначала прочитай `life/прогнозирование.md` (там натальные данные и инструкция по формату). Делай прогноз по двум системам:
1. Западная астрология (транзиты относительно натальной карты)
2. Карта Бацзы (столпы года/месяца/дня, элементы)
Завершай 1–3 конкретными рекомендациями на период. Записывай прогноз в `life/прогнозирование.md` в раздел «Хронология».

## Правило #4 — Obsidian-ссылки
Когда упоминаешь клиентов, компании, методологии — оборачивай в двойные скобки `[[...]]`. Это строит граф связей в Obsidian.
Примеры: `[[Florida Beach]]`, `[[Артём Ариков]]`, `[[ЭММ]]`

## 🟢 ГЛАВНОЕ ПРАВИЛО: ВСЁ ПИШЕШЬ ТОЛЬКО В inbox/

Единственная папка для записи — `inbox/`. **Без исключений.**

Claude разбирает `inbox/` в начале каждой сессии и раскладывает файлы по нужным местам базы (КЛИЕНТЫ/, life/, Tasks Board, WIKI/ и т.д.). Твоя задача — положить информацию в `inbox/` с чёткой разметкой, чтобы Claude понял, куда это относится.

Пиши в inbox/ СРАЗУ, без спроса. Не отвечай «только по твоей команде» — запись в inbox/ это твоя штатная работа.

## Формат файла в inbox/

Имя файла: `ГГГГ-ММ-ДД_тема.md`

Шаблон (обязательные поля):
```markdown
# Тип: [задача / лид / обновление-клиента / идея / решение / голосовое / промт / личное / контент / прогноз]
# Относится к: [клиент: Имя / проект: название / личное: сфера / бизнес / нет привязки]
# Дата: ГГГГ-ММ-ДД ЧЧ:ММ
# Источник: бот
# Срочность: [🔴 срочно / 🟡 обычно / 🟢 не срочно]

[полное содержание — текст, транскрипт, данные]
```

## Примеры

**Лид:**
```markdown
# Тип: лид
# Относится к: клиент: Роллы на районе (Елена Варанкина)
# Дата: 2026-05-27 14:30
# Источник: бот
# Срочность: 🔴 срочно

Елена написала в ТГ: «Могу в понедельник 15–16». Телефон: +79110270389.
⚠️ ТОЛЬКО Telegram, не звонить!
```

**Обновление клиента:**
```markdown
# Тип: обновление-клиента
# Относится к: клиент: Baker Duck (Постэль)
# Дата: 2026-05-25 18:00
# Источник: бот
# Срочность: 🟡 обычно

Артём подтвердил оплату стратегии 9 900₽. Переведёт завтра.
```

**Личное:**
```markdown
# Тип: личное
# Относится к: личное: здоровье
# Дата: 2026-05-20 09:00
# Источник: бот
# Срочность: 🟢 не срочно

Руслан: записался к офтальмологу на 25.05. Упражнения для глаз от Воронкова — делаю каждый день.
```

**Задача:**
```markdown
# Тип: задача
# Относится к: бизнес
# Дата: 2026-05-28 11:00
# Источник: бот
# Срочность: 🟡 обычно

Подготовить презентацию для Роллов на районе к понедельнику. Без терминов — простым языком.
```

**Идея:**
```markdown
# Тип: идея
# Относится к: проект: деятель-в-потоке
# Дата: 2026-05-28 22:00
# Источник: бот
# Срочность: 🟢 не срочно

Идея: делать мини-интервью с клиентами после внедрения — 5 минут на камеру. Собирать для клуба как базу кейсов.
```

## ❌ Что НЕ делать

- ❌ НЕ писать напрямую в `КЛИЕНТЫ/`, `КЛИЕНТЫ-АН/`, `life/` — **только в inbox/**, Claude разнесёт
- ❌ НЕ трогать `Tasks Board.md`, `MISSION_CONTROL.md`, `LIFE_CONTROL.md`
- ❌ НЕ трогать `knowledge-base/`, `WIKI/`, `agents/`, `content/`, `cowork_outputs/`, `RAW/`, `DECISIONS_LOG.md`, `IDEAS_LOG.md`, прочие индексы и логи в корне
- ❌ НЕ создавать `workspace/prompts/` и любые параллельные хранилища промтов

Хочешь что-то добавить в любую из этих зон → пиши в `inbox/` с правильной разметкой, Claude перенесёт.

## 🔮 Прогнозирование

Когда Руслан просит прогноз — сначала прочитай `life/прогнозирование.md` (там натальные данные и инструкция по формату). Делай прогноз по двум системам:
1. Западная астрология (транзиты относительно натальной карты)
2. Карта Бацзы (столпы года/месяца/дня, элементы)

Завершай 1–3 конкретными рекомендациями на период. Результат — **в `inbox/`** (не пиши напрямую в life/прогнозирование.md):
```markdown
# Тип: прогноз
# Относится к: личное: прогнозирование
# Дата: ГГГГ-ММ-ДД
# Источник: бот
# Срочность: 🟢 не срочно

[прогноз]
```

## 🔗 Obsidian-ссылки

Когда упоминаешь клиентов, компании, методологии — оборачивай в двойные скобки `[[...]]`. Это строит граф связей в Obsidian.
Примеры: `[[Florida Beach]]`, `[[Артём Ариков]]`, `[[ЭММ]]`

## 📖 Чтение базы

Читать можешь **всё без ограничений**:
- `Tasks Board.md` — текущие задачи

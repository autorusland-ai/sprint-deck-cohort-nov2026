# Mail Handler

## Когда использовать
- Прочитать письма от клиента
- Поиск по почте
- Отправка письма/КП

## Когда НЕ использовать
- Календарь (→ calendar-keeper)
- Не Gmail почта

## Как формулировать задачу
Что искать (от кого, тема, дата) или кому отправить (кому, тема, тело).
